# Product Demo Video

Turn static product screenshots or designs into a polished, animated demo — no screen recorder, no jittery real cursor, no UI version drift. It frames each screen in a browser or device chrome, glides a synthetic cursor to the exact pixel, ripples the click, zooms to the part that matters, and captions the feature. Built for makers shipping app/SaaS demos, feature announcements, and onboarding walkthroughs (15–90s).

## When it activates

- "Make a product demo video" / "create an app demo video" / "do a SaaS demo".
- "Build a feature announcement video" or "make a UI walkthrough video".
- "Animate product screenshots into a demo" / "add an animated cursor/click to a screenshot".
- "Zoom into part of a UI" to highlight one focal region of a dense dashboard.

## Example prompts

- "Make a 45s demo from these three screenshots, walk the cursor through the signup flow and zoom into the pricing card."
- "Frame this dashboard screenshot in a browser window and add a callout on the analytics panel."
- "Build a feature-announcement video that clicks Export and captions 'One-click export'."

## What's inside

- `SKILL.md` — the demo loop and beat budgets, screenshot capture at 2×, browser/device framing, the frame-driven animated cursor + click ripple, zoom-to-region, callouts and feature captions, and screen-to-screen transitions.
- `references/screenshot-demo.md` — a complete runnable Remotion demo: 2× Playwright capture, frame components, a multi-step cursor composition, and a render command.
- `references/annotation-and-transitions.md` — spotlight masks, arrow/circle callout connectors, a typed caption track, and four transitions with multi-aspect safe-area notes.
