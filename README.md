# E-Commerce Video Skills

> Generate ecommerce / product video — product demos, sale promos, and photo slideshows — straight from your screenshots, prices, and image folders.

## Install

```bash
npx skills add iart-ai/ecommerce-video-skills
```

Works with Claude Code, Cursor, Codex, GitHub Copilot, and 40+ agents.

## What's included

| Skill | What it does |
|---|---|
| [product-demo-video](./product-demo-video) | Turn static product/app screenshots into a polished animated demo — device frames, synthetic cursor + click, zoom-to-region, feature captions. |
| [sale-promo-video](./sale-promo-video) | Punchy 6–15s sale spot — discount reveal, was→now price strike-through, promo code, countdown, CTA, batched across many products. |
| [slideshow-video](./slideshow-video) | Turn a folder of photos into a finished video — per-photo Ken Burns motion, beat-synced transitions, mixed aspect ratios, captions. |

## When it activates

- You ask to make a product demo, app/SaaS walkthrough, or feature-announcement video from screenshots.
- You ask for a sale, promo, discount-reveal, Black Friday, or flash-sale video.
- You ask to turn photos into a slideshow, montage, or recap video with music.
- You want one template rendered across many products, offers, or image folders.

## Example prompts

- "Make a 30s product demo from these dashboard screenshots with an animated cursor and a zoom into the export button."
- "Create a Black Friday promo: 40% off, was $79 now $47, code FLASH40, ends Sunday."
- "Turn this folder of trip photos into a slideshow with Ken Burns motion synced to the music."
- "Batch a promo video for every row in my offers CSV, prices pulled from the data."
- "Build a feature-announcement video framing each screen in a browser window."
